# Local Turístico

Projeto desenvolvido como prática de HTML e CSS, criando uma página turística sobre Busan, na Coreia do Sul.

## Projeto online

Acesse o projeto publicado:

https://vinicius-takahashi.github.io/Local-Turistico/

## Sobre o projeto

O objetivo deste projeto foi construir uma página estática utilizando HTML e CSS, praticando estrutura semântica, organização visual, estilização de elementos, uso de imagens e links externos.

A página apresenta alguns destinos turísticos de Busan, com imagens, descrições, categorias de indicação e links para saber mais sobre cada local.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## O que foi praticado

- Estrutura semântica com HTML
- Uso de `header`, `main`, `section`, `article`, `figure`, `figcaption` e `footer`
- Organização de conteúdo em seções
- Estilização com CSS
- Aplicação de fontes externas
- Uso de imagens
- Criação de divisores visuais
- Estilização de listas e categorias
- Criação de botões com efeito `hover`
- Links externos com `target="_blank"` e `rel="noopener noreferrer"`
- Versionamento com Git
- Publicação do projeto com GitHub Pages

## Layout

O projeto foi desenvolvido com base em um desafio prático de criação de uma página de local turístico.
